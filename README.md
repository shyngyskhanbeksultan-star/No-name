# Бот с проверкой подписки

1. В @BotFather создай бота (`/newbot`), скопируй токен.
2. Запусти бота на хостинге: переменная `BOT_TOKEN` = токен, команда `python bot.py`.
3. Создай **приватный канал**, добавь туда бота **администратором**.
4. Кидай файлы в этот канал (до 2 ГБ). Каждый файл сам станет кнопкой.
   Название кнопки = подпись к файлу (или имя файла).
5. Добавь бота админом в оба канала для проверки подписки.

Не забудь: сразу после шага 3 кинь первый файл сам, чтобы канал не заняли чужие.
